# Start Here

Complete, tested codebase for the expat professional directory, with a base
design system (United States + Brazil color theme) applied throughout.

## See it now
Open `prototype.html` in any browser — no setup needed.

## Launch it
Follow `docs/DEPLOY.md` (~30 min, no coding).

## Four decisions only you can make
1. Name + domain — `docs/NAME_SHORTLIST.md`
2. Launch city — `docs/LAUNCH_PLAYBOOK.md`
3. Accounts — `docs/DEPLOY.md`
4. Final visual polish — the design system is in `docs/DESIGN.md`; swap the
   wordmark, refine the palette, or hand to Claude Code for live iteration

## Document map
`README.md` setup · `CLAUDE.md` orientation for Claude Code ·
`docs/DESIGN.md` the color/type system and why · `docs/PROJECT_PLAN.md` status ·
`docs/BACKEND.md` every API endpoint · `docs/DATABASE.md` data model ·
`docs/SECURITY.md` protections + compliance · `docs/MONETIZATION.md` pricing model ·
`docs/APP_ROADMAP.md` mobile app path · `docs/DEPLOY.md` go-live steps ·
`docs/PRELAUNCH_QA.md` pre-launch checklist · `docs/RECRUITMENT_KIT.md` outreach
scripts · `docs/LAUNCH_PLAYBOOK.md` 4-week plan
